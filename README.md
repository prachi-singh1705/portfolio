# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my technical skills, projects, certifications, achievements, and contact information. Built to create a professional online presence and demonstrate my work in Artificial Intelligence, Data Science, Full Stack Development, and Software Engineering.

**🔗 Live Demo:**  
https://portfolio-omega-ashen-q66tnqedx1.vercel.app/

---

# 📖 Overview

This portfolio serves as my personal website where recruiters, collaborators, and developers can learn more about my background, explore my projects, view certifications, and connect with me.

The website is fully responsive and optimized for desktop, tablet, and mobile devices.

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/prachi-singh1705/portfolio.git
```

### Navigate to the Project

```bash
cd portfolio
```

### Open the Website

Simply open:

```text
index.html
```

Or use **Live Server** in Visual Studio Code.
